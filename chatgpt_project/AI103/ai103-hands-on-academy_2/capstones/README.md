# Combine concepts only after the individual labs

1. Safe retail FAQ — retrieval, safety, source validation, caching.
2. Receipt and refund workflow — extraction, ownership, eligibility, approval, idempotency.
3. Multilingual contact center — PII, translation, grounded responses, optional speech integration.
4. Enterprise research assistant — multiple sources, freshness, concurrent reads, role-specific review.

Each project has its own run.py, README and Databricks launcher. Cloud configuration is inherited
from the individual component labs. These are progressive compositions, not four unrelated frameworks.
