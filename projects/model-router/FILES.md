# File guide

| File | What it does and why it matters |
| --- | --- |
| README.md | Describes the scenario, services, attribution, and expected result. |
| SOURCE-STEPS.md | Records the original walkthrough sequence for reference. |
| RUN-MANUALLY.md | Explains how to reproduce the sample and inspect its output. |
| run.sh | Checks settings, then launches the sample and returns its result. |
| [source/.env.sample](source/.env.sample) | Documents sample configuration. |
| [source/LICENSE](source/LICENSE) | Preserves the license and copyright of the copied upstream code. |
| [source/README.md](source/README.md) | Upstream setup and architecture notes. |
| [source/model-router-chat-completions-observability.py](source/model-router-chat-completions-observability.py) | Demonstrates model-router inference using chat completions observability. |
| [source/model-router-chat-completions-session-affinity.py](source/model-router-chat-completions-session-affinity.py) | Demonstrates model-router inference using chat completions session affinity. |
| [source/model-router-chat-completions.py](source/model-router-chat-completions.py) | Demonstrates model-router inference using chat completions. |
| [source/model-router-foundry-responses.py](source/model-router-foundry-responses.py) | Demonstrates model-router inference using foundry responses. |
| [source/requirements.txt](source/requirements.txt) | Lists Python dependencies. |
| [source/sample.yaml](source/sample.yaml) | Describes the sample for the upstream registry. |
